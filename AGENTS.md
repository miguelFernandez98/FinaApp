# fina-app

Personal finance SPA (React 18 + TypeScript + Vite) wrapped in Capacitor for Android/iOS.

## Commands

| Command | Action |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | `tsc && vite build` — type-check **before** build |
| `npm run lint` | `eslint src/` — clean, 0 issues |
| `npm run preview` | Preview production build |
| `npm run cap:sync` | Sync Capacitor with webDir (`dist`) |
| `npm run cap:android` | Add + sync Android platform |
| `npm run cap:ios` | Add + sync iOS platform |

No tests, no CI, no codegen.

## Architecture

- **Entrypoint**: `src/main.tsx` renders `<App />` inside `<React.StrictMode>`.
- **State**: React Context (`src/context.tsx` — `AppProvider` / `useApp`). Persisted to `localStorage` under key `finanzapp_state`.
- **Pages** (tab-based, driven by `BottomNav`): `home`, `transactions`, `stats`, `profile` — all rendered simultaneously, swapped via `currentPage` state.
- **Overlays**: `Toast` (2.5s auto-dismiss) and `ConfirmDialog` at root level.
- **Exchange rates**: Fetched from Binance/BCV API on mount via `src/utils/exchangeRates.ts`; cached in `localStorage` under `finanzapp_exchange_rates`.
- **Charts**: chart.js + react-chartjs-2 (`BarChart`, `DonutChart`). Global chart registration in `src/chartSetup.ts`, plus `chart.js/auto` import in `main.tsx`.

on## Structure

```
src/
  main.tsx          — entrypoint
  App.tsx           — page router + layout
  context.tsx       — global state (React Context)
  storage.ts        — localStorage read/write
  types.ts          — Transaction, Category, AppState, etc.
  chartSetup.ts     — Chart.js registration
  data/categories.ts — category definitions
  utils/
    helpers.ts      — generateId, getMonthTransactions
    exchangeRates.ts — Binance/BCV rate fetching
  pages/            — 4 tab pages
  components/       — shared UI components
```

## Tooling

- **Package manager**: pnpm (lockfile: `pnpm-lock.yaml`). `package-lock.json` is stale.
- **ESLint**: `eslint.config.js` with `typescript-eslint`, `react-hooks`, `react-refresh` plugins. Run with `npx eslint src/`.
- **TypeScript**: `tsconfig.app.json` for app source, `tsconfig.node.json` for config files. `noUnusedLocals` and `noUnusedParameters` are **strict** in `tsconfig.app.json`.
- **Capacitor config**: `capacitor.config.ts` — appId `com.finaapp.app`, webDir `dist`, dark background `#0a0a0f` for both platforms.

## Conventions

- Spanish UI strings throughout the codebase.
- IDs generated by `generateId()` (in `utils/helpers.ts`), not UUID.
- Font Awesome classes prefixed with `fa-` (v6 free).
- Fonts: DM Sans (body) + Space Grotesk (headings) loaded from Google Fonts in `index.html`.
- `.gitignore` excludes: `node_modules`, `dist`, `.capacitor`, `android/`, `ios/`, `*.local`.
